# StudLife — «Складнощі студентського життя»

Браузерна RPG про студента Політеху в общазі «Одинадцятка». Чистий
HTML/CSS/JS без рушіїв, Canvas у нативній роздільності арту (1672×941).
Тексти гри й коментарі — українською, код — англійською.

**ПЕРШ НІЖ ЩОСЬ РОБИТИ, прочитай `PROJECT_HANDOFF.md`** — там повний стан
проєкту, всі системи, пайплайни, тест-хеші та правила роботи з авторкою.

Ключові документи: `GAME_DESIGN.md` (геймдизайн), `ART_DESIGN.md`
(арт + усі промпти генерації), `ROADMAP.md` (етапи, прогрес).

Залізні правила:
- світло НЕ запікається в арт — тільки код (плавні градієнти, без дизерингу)
- фоновий арт НЕ ресемплиться — у гру в нативному розмірі
- аркуші персонажів обробляє `tools/process_chars.html` (маджента-хромакей,
  авто-нарізка) — не різати руками
- зміни перевіряй скріншотом через headless chrome з
  `--allow-file-access-from-files`
- авторка (Даша) сама редагує координати/конфіги і ріже арт у Photopea —
  для нових систем додавай візуальні редактори (як `#chars-geo`)
