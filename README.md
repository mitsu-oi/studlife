# 🎓 Складнощі студентського життя

Браузерна гра про будні студента Львівської політехніки, який живе
в гуртожитку №11 («Одинадцятка») і має протриматись **30 днів до стипендії**.

**▶️ [Грати](https://ІМ_Я.github.io/studlife/)** — відкривається просто в браузері,
нічого встановлювати не треба.

---

## Про що це

Балансуєш п'ять шкал — 💰 гроші, ⚡ енергія, 🧠 менталочка, 👥 соціалка,
📚 навчання — і щодня вирішуєш звичайні студентські дилеми: піти на пари
чи на підробіток, ризикнути котлетою в їдальні чи взяти булочку, бігти
через пів міста між корпусами чи забити на пару.

Кожен день — ранок, день, вечір і ніч. Наприкінці місяця — одна з кількох
кінцівок, залежно від того, як ти прожив ці тридцять днів.

## Що всередині

- **Жива кімната** — троє сусідів мешкають своїм життям: ходять, читають,
  грають на гітарі, лягають спати. Стан кімнати відображає твої шкали:
  занедбав себе — з'являється безлад.
- **🪳 Тарган Борис** — повзає по стінах і стелі, ховається за меблі.
  Можна прибити тапком. Лічильник іде у фінальну статистику.
- **Форс-мажори** — прорвало трубу, помер інтернет, навала тарганів,
  раптова перевірка коменданта. Не вирішиш — тектиме щодня.
- **Сусіди й квести** — з відкладеною нагородою: допоміг сьогодні,
  врятували перед сесією через тиждень.
- **Мінігри** — аркада «Борис біжить» на купленому Xbox, мікробізнес
  на принтері (замовлення сусідів, скінчилась фарба, конкуренти з 7-го поверху).
- **🤖 ШІ-картки** — частину подій вигадує ШІ, враховуючи твій стан і минулі
  вибори. Іноді картка стає продовженням попереднього рішення: промок
  під зливою → тепер щось із цього випливає. Якщо ШІ недоступний, гра
  просто грає на рукописних картках, і гравець нічого не помічає.

## Технології

Чистий **HTML + CSS + JavaScript**, без рушіїв і збірок — гра відкривається
подвійним кліком по `index.html`. Сцена — Canvas 2D у нативній роздільності
арту (1672×941). Прогрес зберігається в `localStorage`.

ШІ-картки обслуговує невелика serverless-функція на Cloudflare Workers
(`server/worker.js`) — вона ховає ключ API, щоб той не потрапив у код гри.
Інструкція, як підняти свою: `server/README.md`.

## Структура

```
index.html          каркас: HUD / канвас / зона рішень / вікна
css/style.css       усе оформлення
js/                 логіка: стан, картки, персонажі, сцена, мінігри, ШІ
data/               контент: події, квести, форс-мажори, покупки, принтер
assets/sprites/     готова графіка
tools/              обробники спрайтів (хромакей, нарізка, масштаб)
server/             «поштова скринька» для ШІ-карток
```

Детальніше — у `PROJECT_HANDOFF.md`, `GAME_DESIGN.md`, `ART_DESIGN.md`, `ROADMAP.md`.
